## منطق فرانت‌اند (خلاصه)

- **اعتبارسنجی کد ملی:** ۱۰ رقم، الگوریتم کنترل (mod 11).
- **شماره موبایل:** عدد ۱۰ رقم (بدون صفر اول) – مثلاً `9123456789`. در بک‌اند با +98 کامل می‌شود.
- **درخواست OTP:** ارسال `{ nationalId, phone }` به `POST /auth/request-otp`.
- **تأیید OTP:** ارسال `{ nationalId, phone, otp }` به `POST /auth/verify`.

بک‌اند همان منطق قبلی را دارد: تشخیص کاربر جدید/قدیم، مغایرت، ذخیره موقت، ایجاد کاربر بدون اکانت (برای جدید)، و بازگرداندن اطلاعات اکانت.

**پس از تأیید موفق (بسته به پاسخ بک‌اند):**
- اگر کاربر **جدید** است (`isNewUser: true`) ← هدایت به صفحه **درخواست نقش اولیه** (بدون اکانت).
- اگر کاربر **قدیمی** است و **چند اکانت** دارد ← هدایت به صفحه **انتخاب اکانت**.
- اگر کاربر قدیمی است و **فقط یک اکانت** دارد ← هدایت به **داشبورد همان اکانت**.

# 🧪 جزئیات امنیتی و بک‌اند (تکمیل)

## `POST /auth/request-otp`
- **بدن:** `{ nationalId, phoneNumberWithoutPrefix }` (مثلاً `9123456789`). شماره کامل با +98 در سرور ساخته شود.
- **بررسی مغایرت:** اگر کد ملی در دیتابیس باشد ولی شماره (با +98) متفاوت باشد → پاسخ `409`.
- **نرخ محدودیت:** هر ملیت ۳ بار در ساعت، هر IP ۱۰ بار در ساعت.
- **اگر کاربر جدید:** ذخیره در Redis با کلید `pending_user:{nationalId}` (شامل شماره کامل).
- **ارسال OTP** (با سرویس پیامک ایرانی).

## `POST /auth/verify`
- **بدن:** `{ nationalId, phoneNumberWithoutPrefix, otp }`
- **بررسی OTP** از Redis.
- **اگر کاربر جدید:** ایجاد رکورد در جدول `users` با `national_id`, `phone`, `phone_verified_at = now()`، `national_id_verified_at = NULL` (سطح ۲ تأیید نشده). **هیچ اکانتی ساخته نمی‌شود.**
- **اگر کاربر قدیمی:** به‌روزرسانی `phone_verified_at` و دریافت اکانت‌ها.
- **تولید JWT** با `userId` و `level: 1`.

## مدل داده (حداقل تا این مرحله)

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY,
    national_id VARCHAR(10) UNIQUE NOT NULL,
    phone VARCHAR(13) UNIQUE NOT NULL, -- +989123456789
    phone_verified_at TIMESTAMP,
    national_id_verified_at TIMESTAMP, -- سطح 2
    created_at TIMESTAMP
);
-- هنوز جدول accounts و ... نداریم (مرحله بعد)
```

- **هشدار سوءاستفاده:** متن قرمز رنگ در پایین صفحه نمایش داده شود.
